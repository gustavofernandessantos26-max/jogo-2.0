// ═══════════════════════════════════════════════════════ // STREET DASH — Subway Surfers Clone // Pure Canvas 2D — sem dependências externas // ═══════════════════════════════════════════════════════ const canvas = document.getElementById('gameCanvas'); const ctx = canvas.getContext('2d'); // ── Screens ────────────────────────────────────────── const screens = { start: document.getElementById('screen-start'), game: document.getElementById('screen-game'), gameover: document.getElementById('screen-gameover'), }; function showScreen(name) { Object.values(screens).forEach(s => s.classList.remove('active')); screens[name].classList.add('active'); } // ── HUD refs ───────────────────────────────────────── const scoreDisplay = document.getElementById('score-display'); const coinsDisplay = document.getElementById('coins-display'); const multDisplay = document.getElementById('multiplier-display'); // ── Constants ───────────────────────────────────────── const LANES = 3; const LANE_W = 120; const BASE_SPEED = 6; const GRAVITY = 0.7; const JUMP_FORCE = -16; const SLIDE_FRAMES = 40; const ANIM_RATE = 8; // frames per sprite step // ── Palette ────────────────────────────────────────── const COL = { sky1:'#0d0221', sky2:'#1a0533', ground:'#1c1c3a', track:'#252545', rail:'#00f5d4', neon:'#00f5d4', neon2:'#f72585', gold:'#ffd60a', white:'#eef1ff', shadow:'rgba(0,0,0,0.6)', }; // ── Game State ───────────────────────────────────────── let state, raf; function initState() { return { running: false, paused: false, score: 0, coins: 0, distance: 0, speed: BASE_SPEED, frame: 0, spawnTimer:0, player: { lane: 1, // 0 left | 1 center | 2 right x: 0, // set in resize y: 0, // ground y vy: 0, onGround:true, jumping: false, sliding: false, slideTimer: 0, invincible: false, invTimer: 0, animFrame: 0, animTimer: 0, w: 44, h: 72, }, obstacles: [], coins_obj: [], particles: [], bgLayers: initBgLayers(), trails: [], multiplier: 1, multTimer: 0, }; } // ─── Background layers ──────────────────────────────── function initBgLayers() { return [ { z:0.2, y: 0, items: randomBuildings(12, 0.2) }, { z:0.5, y: 0, items: randomBuildings(8, 0.5) }, ]; } function randomBuildings(count, z) { const arr = []; for (let i = 0; i < count; i++) { arr.push({ x: Math.random() * 2000, w: 60 + Math.random() * 120, h: 80 + Math.random() * 200, hue: Math.random() > 0.5 ? 270 : 200, lit: Math.random() > 0.4, }); } return arr; } // ═══════════════════════════════════════════════════════ // CANVAS RESIZE // ═══════════════════════════════════════════════════════ let W, H, GROUND_Y, LANE_CENTERS; function resize() { const container = screens.game; W = canvas.width = container.clientWidth || window.innerWidth; H = canvas.height = container.clientHeight || window.innerHeight; GROUND_Y = H * 0.72; const cx = W / 2; LANE_CENTERS = [cx - LANE_W, cx, cx + LANE_W]; if (state) { const p = state.player; p.x = LANE_CENTERS[p.lane]; p.y = GROUND_Y; } } window.addEventListener('resize', resize); resize(); // ═══════════════════════════════════════════════════════ // INPUT // ═══════════════════════════════════════════════════════ let touchStartX = 0, touchStartY = 0; document.addEventListener('keydown', e => { if (!state?.running || state.paused) return; if (e.key==='ArrowLeft' || e.key==='a') changeLane(-1); if (e.key==='ArrowRight' || e.key==='d') changeLane(+1); if (e.key==='ArrowUp' || e.key==='w' || e.key===' ') jump(); if (e.key==='ArrowDown' || e.key==='s') slide(); }); canvas.addEventListener('touchstart', e => { touchStartX = e.touches[0].clientX; touchStartY = e.touches[0].clientY; }, {passive:true}); canvas.addEventListener('touchend', e => { if (!state?.running || state.paused) return; const dx = e.changedTouches[0].clientX - touchStartX; const dy = e.changedTouches[0].clientY - touchStartY; if (Math.abs(dx) > Math.abs(dy)) { if (dx < -30) changeLane(-1); if (dx > 30) changeLane(+1); } else { if (dy < -30) jump(); if (dy > 30) slide(); } }, {passive:true}); function changeLane(dir) { const p = state.player; const nl = p.lane + dir; if (nl < 0 || nl >= LANES) return; p.lane = nl; p.x = LANE_CENTERS[nl]; spawnTrail(p.x, p.y - p.h/2, dir < 0 ? COL.neon : COL.neon2); } function jump() { const p = state.player; if (p.onGround) { p.vy = JUMP_FORCE; p.onGround = false; p.jumping = true; p.sliding = false; spawnParticles(p.x, p.y, COL.neon, 8); } } function slide() { const p = state.player; if (!p.onGround) return; p.sliding = true; p.slideTimer = SLIDE_FRAMES; p.jumping = false; } // ═══════════════════════════════════════════════════════ // SPAWNING // ═══════════════════════════════════════════════════════ const OBSTACLE_TYPES = ['train','barrier','low_barrier','double_barrier']; function spawnObstacle() { const type = OBSTACLE_TYPES[Math.floor(Math.random() * OBSTACLE_TYPES.length)]; const lane = Math.floor(Math.random() * LANES); let w = 60, h = 80, canSlide = false, canJump = true, lowH = false; if (type === 'train') { w=80; h=100; } if (type === 'barrier') { w=55; h=65; } if (type === 'low_barrier') { w=60; h=35; canSlide=true; lowH=true; } if (type === 'double_barrier'){ // two lanes blocked const l2 = (lane + 1) % LANES; state.obstacles.push({ lane:l2, x: LANE_CENTERS[l2], y: -h, w, h, type }); } state.obstacles.push({ lane, x: LANE_CENTERS[lane] + W, y: GROUND_Y - h, w, h, type, canSlide, lowH }); } function spawnCoin() { const lane = Math.floor(Math.random() * LANES); const count = 3 + Math.floor(Math.random() * 5); for (let i = 0; i < count; i++) { state.coins_obj.push({ lane, collected:false, x: LANE_CENTERS[lane] + W + i * 60, y: GROUND_Y - 40 - Math.sin(i * 0.8) * 40, r: 12, anim: Math.random() * Math.PI * 2, }); } } function spawnTrail(x, y, col) { state.trails.push({ x, y, alpha:1, col, r: 18 }); } function spawnParticles(x, y, col, n=12) { for (let i=0; i ox && py < oy + ob.h && py + ph > oy ); } function checkCoin(p, c) { const dx = p.x - c.x; const dy = (p.y - p.h/2) - c.y; return Math.sqrt(dx*dx + dy*dy) < p.w/2 + c.r; } // ═══════════════════════════════════════════════════════ // MAIN UPDATE LOOP // ═══════════════════════════════════════════════════════ function update() { if (!state.running || state.paused) return; const p = state.player; state.frame++; state.distance += state.speed; state.score = Math.floor(state.distance / 10); // Speed ramp state.speed = BASE_SPEED + Math.floor(state.distance / 3000) * 0.5; // Multiplier state.multTimer++; if (state.multTimer > 200) { state.multTimer = 0; state.multiplier = Math.min(state.multiplier + 1, 5); } // Player physics if (!p.onGround) { p.vy += GRAVITY; p.y += p.vy; if (p.y >= GROUND_Y) { p.y = GROUND_Y; p.vy = 0; p.onGround = true; p.jumping = false; spawnParticles(p.x, p.y, '#555', 6); } } // Slide if (p.sliding) { p.slideTimer--; if (p.slideTimer <= 0) p.sliding = false; } // Invincibility if (p.invincible) { p.invTimer--; if (p.invTimer <= 0) p.invincible = false; } // Player anim p.animTimer++; if (p.animTimer >= ANIM_RATE) { p.animTimer = 0; p.animFrame = (p.animFrame + 1) % 4; } // BG parallax state.bgLayers.forEach(layer => { layer.items.forEach(b => { b.x -= state.speed * layer.z; if (b.x + b.w < 0) b.x = W + Math.random() * 200; }); }); // Spawn state.spawnTimer++; const interval = Math.max(60, 130 - Math.floor(state.distance / 1500) * 8); if (state.spawnTimer > interval) { state.spawnTimer = 0; if (Math.random() < 0.7) spawnObstacle(); if (Math.random() < 0.5) spawnCoin(); } // Move obstacles state.obstacles = state.obstacles.filter(ob => { ob.x -= state.speed; if (!p.invincible && checkCollision(p, ob)) { // Hit! if (ob.canSlide && p.sliding) return false; // slid under it p.invincible = true; p.invTimer = 80; spawnParticles(p.x, p.y - p.h/2, COL.neon2, 20); gameOver(); return false; } return ob.x + ob.w > -W/2; }); // Move coins state.coins_obj = state.coins_obj.filter(c => { c.x -= state.speed; c.anim += 0.08; if (!c.collected && checkCoin(p, c)) { c.collected = true; state.coins += state.multiplier; spawnParticles(c.x, c.y, COL.gold, 6); return false; } return c.x + c.r > 0; }); // Trails state.trails = state.trails.filter(t => { t.alpha -= 0.06; t.r += 2; return t.alpha > 0; }); // Particles state.particles = state.particles.filter(p2 => { p2.x += p2.vx; p2.y += p2.vy; p2.vy += 0.2; p2.alpha -= 0.03; return p2.alpha > 0; }); // HUD scoreDisplay.textContent = state.score * state.multiplier; coinsDisplay.textContent = state.coins; multDisplay.textContent = `x${state.multiplier}`; } // ═══════════════════════════════════════════════════════ // DRAW // ═══════════════════════════════════════════════════════ function draw() { ctx.clearRect(0, 0, W, H); drawBackground(); drawTrack(); drawTrails(); drawCoins(); drawObstacles(); drawPlayer(); drawParticles(); } // ── Background ───────────────────────────────────────── function drawBackground() { // Sky gradient const sky = ctx.createLinearGradient(0, 0, 0, GROUND_Y); sky.addColorStop(0, COL.sky1); sky.addColorStop(1, COL.sky2); ctx.fillStyle = sky; ctx.fillRect(0, 0, W, GROUND_Y); // Buildings (far) drawBuildings(state.bgLayers[0], 0.4, H * 0.4); // Buildings (near) drawBuildings(state.bgLayers[1], 0.7, H * 0.2); // Ground const gnd = ctx.createLinearGradient(0, GROUND_Y, 0, H); gnd.addColorStop(0, '#1c1c3a'); gnd.addColorStop(1, '#0d0221'); ctx.fillStyle = gnd; ctx.fillRect(0, GROUND_Y, W, H - GROUND_Y); } function drawBuildings(layer, alpha, maxH) { ctx.save(); ctx.globalAlpha = alpha; layer.items.forEach(b => { const bY = GROUND_Y - b.h; // Building body ctx.fillStyle = `hsl(${b.hue}, 30%, 12%)`; ctx.fillRect(b.x - b.w/2, bY, b.w, b.h); // Outline ctx.strokeStyle = `hsla(${b.hue}, 60%, 35%, 0.3)`; ctx.lineWidth = 1; ctx.strokeRect(b.x - b.w/2, bY, b.w, b.h); // Windows if (b.lit) { const cols = Math.floor(b.w / 18); const rows = Math.floor(b.h / 22); for (let r=1; r { const oy = GROUND_Y - ob.h; const ox = ob.x - ob.w/2; ctx.save(); if (ob.type === 'train' || ob.type === 'double_barrier') { // Train const grad = ctx.createLinearGradient(ox, oy, ox+ob.w, oy+ob.h); grad.addColorStop(0, '#2d2d4e'); grad.addColorStop(1, '#1a1a35'); ctx.fillStyle = grad; roundRect(ctx, ox, oy, ob.w, ob.h, 6); ctx.fill(); ctx.strokeStyle = COL.neon2; ctx.lineWidth = 2; ctx.shadowBlur = 8; ctx.shadowColor = COL.neon2; roundRect(ctx, ox, oy, ob.w, ob.h, 6); ctx.stroke(); ctx.shadowBlur = 0; // Windows ctx.fillStyle = 'rgba(0,245,212,0.3)'; for (let i = 0; i < 3; i++) { ctx.fillRect(ox + 8 + i*22, oy + 10, 16, 20); } // Stripe ctx.fillStyle = COL.neon2; ctx.fillRect(ox, oy + ob.h*0.6, ob.w, 3); } else if (ob.type === 'barrier') { // Barrier ctx.fillStyle = '#ff6b00'; ctx.fillRect(ox, oy, ob.w, ob.h); ctx.fillStyle = '#000'; for (let i = 0; i < 3; i++) { ctx.fillRect(ox, oy + i * (ob.h/3), ob.w, ob.h/6); } ctx.strokeStyle = '#ff6b00'; ctx.lineWidth = 2; ctx.shadowBlur = 12; ctx.shadowColor = '#ff6b00'; ctx.strokeRect(ox, oy, ob.w, ob.h); ctx.shadowBlur = 0; } else if (ob.type === 'low_barrier') { // Low barrier (slide under) ctx.fillStyle = '#7209b7'; roundRect(ctx, ox, oy, ob.w, ob.h, 4); ctx.fill(); ctx.strokeStyle = COL.neon; ctx.lineWidth = 1.5; ctx.shadowBlur = 8; ctx.shadowColor = COL.neon; roundRect(ctx, ox, oy, ob.w, ob.h, 4); ctx.stroke(); ctx.shadowBlur = 0; // Arrow hint ctx.fillStyle = COL.neon; ctx.font = 'bold 14px Arial'; ctx.textAlign = 'center'; ctx.fillText('▼', ob.x, oy - 8); } ctx.restore(); }); } // ── Coins ────────────────────────────────────────────── function drawCoins() { state.coins_obj.forEach(c => { ctx.save(); const glow = Math.sin(c.anim) * 0.3 + 0.7; ctx.shadowBlur = 10; ctx.shadowColor = COL.gold; ctx.fillStyle = `hsl(45, 100%, ${50 + glow*15}%)`; ctx.beginPath(); ctx.arc(c.x, c.y, c.r, 0, Math.PI*2); ctx.fill(); ctx.fillStyle = 'rgba(255,255,255,0.5)'; ctx.beginPath(); ctx.arc(c.x - c.r*0.3, c.y - c.r*0.3, c.r*0.35, 0, Math.PI*2); ctx.fill(); ctx.shadowBlur = 0; ctx.fillStyle = 'rgba(0,0,0,0.4)'; ctx.font = `bold ${c.r}px Arial`; ctx.textAlign = 'center'; ctx.textBaseline = 'middle'; ctx.fillText('$', c.x, c.y); ctx.restore(); }); } // ── Trails & Particles ───────────────────────────────── function drawTrails() { state.trails.forEach(t => { ctx.save(); ctx.globalAlpha = t.alpha * 0.4; ctx.strokeStyle = t.col; ctx.lineWidth = 3; ctx.shadowBlur = 20; ctx.shadowColor = t.col; ctx.beginPath(); ctx.arc(t.x, t.y, t.r, 0, Math.PI*2); ctx.stroke(); ctx.restore(); }); } function drawParticles() { state.particles.forEach(p2 => { ctx.save(); ctx.globalAlpha = p2.alpha; ctx.fillStyle = p2.col; ctx.shadowBlur = 8; ctx.shadowColor = p2.col; ctx.beginPath(); ctx.arc(p2.x, p2.y, p2.r, 0, Math.PI*2); ctx.fill(); ctx.restore(); }); } // ── Helper ───────────────────────────────────────────── function roundRect(ctx, x, y, w, h, r) { ctx.beginPath(); ctx.moveTo(x + r, y); ctx.lineTo(x + w - r, y); ctx.quadraticCurveTo(x+w, y, x+w, y+r); ctx.lineTo(x+w, y+h-r); ctx.quadraticCurveTo(x+w, y+h, x+w-r, y+h); ctx.lineTo(x+r, y+h); ctx.quadraticCurveTo(x, y+h, x, y+h-r); ctx.lineTo(x, y+r); ctx.quadraticCurveTo(x, y, x+r, y); ctx.closePath(); } // ═══════════════════════════════════════════════════════ // GAME LOOP // ═══════════════════════════════════════════════════════ function loop() { update(); draw(); raf = requestAnimationFrame(loop); } // ═══════════════════════════════════════════════════════ // GAME OVER / START / RESTART // ═══════════════════════════════════════════════════════ function gameOver() { state.running = false; cancelAnimationFrame(raf);
